# Testing_and_Comparison_of_Entropy_Methods
# Testing and Comparison of Entropy Methods for Online CPD  A Python library and testing framework for online Change Point Detection (CPD) in time series based on entropy metrics.  ## Solution Overview * Online data processing in a sliding window with dynamic baseline calibration and the three-sigma rule. * Synthetic data generator for 5 types of changes: mean shift, variance change, autoregression shift, frequency change, and outliers. * Evaluation module for detection quality: calculation of AUPRC, F1-score, ADD (Average Delay of Detection), ARL (Average Run Length), and computational complexity.  ## Implemented Algorithms 1. **Parametric:** Shannon, Renyi, Tsallis, KLD. 2. **Pattern-based:** Permutation, Dispersion, Bubble, Slope. 3. **Complexity-based:** Approximate, Sample.   ## Tech Stack Python 3.12, NumPy, SciPy, Pandas.
